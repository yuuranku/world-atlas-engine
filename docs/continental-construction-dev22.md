# 确定性大陆构造 · dev22

dev21 的大陆构造把数量当成生成后的验收条件，只尝试四个逐次缩短的板块运动历史。海岸扰动、极地偏置和全局海平面仍可能合并两个大陆，或者淹没较小大陆；缩短运动历史并不单调地解决这些问题。冻结的五大陆输入因此在四个候选中分别得到两、四、三、四个主要陆块。

dev22 计算一次完整运动历史，由引擎内部求解真实地形场的约束。各大陆核按球面面积配额生长，每一个新单元都有到其核的四邻域连接，相邻大陆之间保留海洋。极地大陆核计入请求的大陆总数。构造网格上的配额完成检查与最终网格的面积重采样检查分开，避免以原生单元精度误拒绝来源网格的正常量化误差。

连续地形场的求解保留实际认证过的扰动幅度。它使用原地形的高程、坡度及同源大陆场，没有由助手手调种子、地图坐标或大陆标签。非单调可行条件下只返回已认证的端点，不声称得到全局最大幅度。诊断保存候选、可行端点和结果的四邻域／八邻域主要陆块数、面积裕量、极地状态、保留幅度以及海陆符号变化面积。

地图原有的完整海洋接缝条件也参与构造：在大陆核之间最大的经度间隙保留海洋通道，极地帽使用既有的纬度排除规则。构造网格保留一格取样裕度，并按目标网格的真实行列索引认证通道，处理 720 到 2176 等非整数分辨率比；不在成品地图上切掉陆地，最终所需通道宽度不变。

高分辨率地形经过地貌处理后仍须满足同一大陆约束。最终高程符号、海陆掩码和大陆身份共用实际求解的物理地面，后续气候、水系、城市、交通及行政区划使用正常公开生成接口。四邻域／八邻域连通验收和主要陆块面积门槛保留，不能以标签分区冒充真实大陆。

该修改是通用引擎构造规则，不包含冻结输入种子或特定地图的分支。回归覆盖原失败输入的构造、后续地貌层和极地大陆计数。无法认证的内部可行端点仍报出具体错误并保留记录；算法驱动不代表所有参数组合、资源条件或程序实现都永远不会失败。

# 行政边界绘制修复

dev18 的连续竞争前沿仍有原生格尺度的水平平台和直角。SVG 已经使用圆角描边，因此更改 linejoin 不能消除这些几何折角。概览额外执行覆盖简化，还会把细分曲线变成长折线。

dev19 将行政模拟和制图分开：模拟继续决定国家、省份及其归属；在绘制阶段，用已锁定的 Mapshaper 0.7.56 处理一次共边弧图。国省填色、国界、省界、名义领土、概览、切片及球面主题从这份覆盖派生，不独立平滑各国轮廓或只改墨线。概览保留准备好的行政曲线，不再执行第二次行政简化。

内部共边最大移动 0.35 原生单位。外部边、行政交汇点固定；局部移动不能跨越原生观察中心，不能新增交叉、白缝或重叠，不能消除小飞地、组件或孔。遇到这些约束，只抑制受影响的局部移动。真实受约束的折角可能仍存在；不添加随机波浪来掩盖它们。

行政概览保留完整矢量曲线，其单主题文件使用已有原生导出的 64 MiB 上限；其余简化主题保留 10 MiB 上限，所有概览主题总量限制为 64 MiB。行政概览因此会比旧抽稀文件大；近景仍按原切片加载。

局部实际样本中，一单位水平平台消失，覆盖保持完整，原生中心归属变化为零。这是绘制几何的专项检查，不代表全部种子或所有行政划分已经地理合理。自然边界、交通联系和政治历史的职责与资料见 [dev18 研究记录](cartographic-line-quality-dev18.md)。

`refresh_review_administrations` 接收保存的模拟社会和已交付的绘制社会，要求国省数组与层级一致，并核对场景身份。它在全新目录复制既有地图，只重建行政导出、概览、切片、球面行政主题及名义领土图层。地形、河流、道路、城市、导航与旅行数据复用，记录来源、几何指纹和阶段耗时。此流程不属于重新随机生成世界。

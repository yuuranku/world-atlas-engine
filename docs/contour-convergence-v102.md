# 等高线终止条件修复

新随机世界的地形种子 4077593202、2176×1088 分辨率，在高度
3325.016324324542 米的 native cell (99, 101) 触发 40 次细分上限。
允许继续细分后，张量 PCHIP 的保守舍入区间仍包含该高度，直到坐标
成为相邻 binary64 值；这些格子不存在可表示的内部查询坐标。

本修复移除任意深度上限，按可细分的坐标继续求证。终端格子穷举全部
四个可表示的点：无跨边时结束，有两条跨边时保留共享真实边根的线段。
有歧义的终端格子和百万节点异常仍明确失败。可证明单调的普通曲线
继续使用原有方向证书和自适应曲线编码。未改变地形、等高线级别、
精度容差、输入种子或画法。

针对性验证：上述真实故障格子从异常退出变为 2 条曲线、574 个顶点，
最大高度残差 2.4101609596982598e-11 米。现有 implicit terrain 的
17 项测试通过。按用户要求未执行整套测试或独立世界复现。

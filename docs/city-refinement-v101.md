# 城市精细化与统一空间关系

本轮沿用罗特世界 v97 的地形、种子、时代和人口等设置。当前严格设置显式声明没有额外飞行能力；原输入、有效设置和 151 个引擎文件的 SHA-256 保存于 `D:/2/world-city-v101-inputs.json`。完整世界通过 `world_atlas world` 重算，输出使用独立目录，城市细节仍在打开时才生成。

## 可检验的改动

- 宫殿使用轴线院落、柱廊宫院、商人宫邸、堡宫、厅堂外庭、坡地台院及园林亭院。形制有三个种子变体，人口决定宫城面积和翼楼数量。各殿宇地基高差最多 4 m。
- 普通房屋沿附近真实街道定向，进深、面宽和退距随地块变化。陶瓦、板岩、木瓦、灰白平顶及琉璃材料提供同城色差；屋面绘制亮暗面、屋脊和四坡斜脊。材料气候分支目前使用纬度近似，不声称已模拟建筑热工。
- 港区先预留沿岸土地。岸线码头、栈桥、泊船、仓库、防波堤和灯标检查实际水陆。人口决定泊位数；河港使用河中心作为岸线搜索上界，避免把对岸当作泊位。
- 道路在宫城和公共用地避让完成后参与城门及城墙计算；民居最后检查全部道路和城防。沿河且与河岸平行的冗余城墙被移除。经度接缝的道路裁切使用长度归一化，消除近乎平行边造成的浮点差异。
- 湖泊从真实局部凹地的溢流水位求得。水库先调整水道上游水面，河谷修整后再次求湖岸；水面、道路和可建设地共用 signed depth。支流沿上坡反向寻路并与主河共享汇流节点，宽河附近可生成内河港。
- 近岸岛屿使用种子控制不等频轮廓、长宽、朝向和高程，并避让航道。农舍有通到房屋边缘入口的支路，村名使用语言谱系中的独立词根。
- 港口候选先检查与原城市的干陆地连通，再比较岸线距离与避风条件。细化海岸接入段可以经过粗网格水格中的真实陆地，最终仍裁到精确物理陆地；斜向格点交接保留相邻正交格。完整认可世界的 347 个港口、道路桥梁和导航联调通过。
- 变宽河道逐段构造水面并在节点圆角连接，避免急弯水面自折叠把河中心挖成陆地。海岸政区叠加不继承展示层固定精度，保留真实海岸顶点。
- 房屋轮廓与屋脊按米制宽度绘制，减少远景黑块；地标、城墙与树冠使用同方向的阴影。树冠分为三组材质色，轮廓保持在原有树冠半径内。界面刷新保留已经验证的港口及城市位置。

# 1.3.0 · 断层式岸线、带状山系与离岸群岛

这一版只改变物理地形层，保留原有连续高度场、海平面切分、全分辨率细节和 SVG 等高线画法。旧版 v38 目录不覆盖，仍可用原引擎版本复现。

## 这次改动

- **岸线**：在连续地壳势场的海平面切分之前，沿已测量的大陆边缘施加带接力节点的分段断层位移。每个海湾、海岬、裂谷口和被动边缘有不同长度、横向滑移和转折；再叠加受岸线距离约束的断块陆架场与中尺度接力断裂。这样海岸不是把一个圆形噪声阈值直接切出来，而是会出现错位陆架、钩状海湾和不对称岬角。
- **山系**：当前和古板块聚合边界各自生成带状褶皱场。距离边界决定山系肩部宽度，平行子带、断续闸口和沿走向门控决定山脊的连续性与高低变化；旧边界只留下更宽、更低的侵蚀残余。
- **群岛**：接回已有的架构化群岛生成器，将大陆架碎片、岛弧、热点链在参考场上先生成，再以周期插值回 720×360 参考场，最后参与同一次海平面切分。群岛不是渲染后贴图，因此后续水系和人文层看到的仍是同一份陆海字段。

## 设计依据

采用现有 `references/geography.md` 中的地理约束：板块边缘先决定大陆形态，海岸在多尺度构造位移后切海平面；山系需要走向、复合脊、山麓和盆地过渡；岛屿按大陆架碎片、岛弧和热点链分家族并保持尺度差异。噪声只承担局部侵蚀和分段门控，不再独自决定世界大轮廓。

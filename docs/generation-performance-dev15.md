# 生成提速与减少重复工作：1.4.0.dev15

本版减少连续地形求解中的重复计算，并精简普通世界生成的 skill 工作流。沿用现有分辨率、物理模型、求根精度、城市规则和画法；格温卡瑞不重新生成。

## 实际计算

不可变原生地形的水平 PCHIP 多项式只构建一次。SciPy 仍负责系数计算，周期幽灵列保证每个保留区间的两端都是内部节点。采样、标量轮廓、模型切换事件和范围证书共用这些系数；随横坐标变化的垂直 PCHIP 继续按原定义计算。

范围证书将四行水平多项式及三组行差合成批次。每次乘加、向外舍入和梯度计算保持原有顺序，未放宽任何精度或几何阈值。

系数按需分配，构建时以 64 行为一批限制临时内存。2176×1088 地形的地面与排水两份缓存合计 151,519,232 字节，约 144.5 MiB。派生缓存不进入 spawn 序列化；每个实际使用它的工作进程自行构建，避免反复传输完整系数栅格。

## 有界对照

读取格温卡瑞现有物理字段与水文网格，在阿尔鲁德附近的原生范围 `[424,591,428,595]` 查询 65,536 个配对点、1,024 个范围证书，并求解三个高度的细等高线。原实现来自公开 dev14；优化实现来自发布前的开发源码。下表来自未启用 profiler、顺序执行的直接计时，不与并发测试混跑。

| 项目 | 原实现 | 优化实现 |
| --- | ---: | ---: |
| 加载并构建地形场 | 4.414 秒 | 4.077 秒 |
| 首次配对点采样 | 0.479 秒 | 0.378 秒 |
| 范围证书 | 0.210 秒 | 0.183 秒 |
| 局部细等高线求解 | 6.575 秒 | 4.540 秒 |

此样本的等高线求解时间减少约 31%，速度约为原来的 1.45 倍。重复配对采样的两次计时变化很小，不据此宣称采样整体大幅提速。14 份数组的 SHA-256 全部一致，包括采样值、范围/梯度证书及 531 个等高线顶点；原生地形未改动。

这是生成引擎真实地形求解路径的局部对照，并非完整世界耗时或耗电测量。此次未重算全世界，不能将 1.45 倍外推为整次生成加速倍数。

复测入口：`python tools/benchmark_terrain_sampling.py <现有世界> <全新结果目录> --query 424 591 428 595`。需对照时分别使用公开旧版本和新源码的解释器环境；`--profile` 仅用于责任层定位，不与直接计时混合比较。

## 流程

普通生成只运行一个候选和一套地形/下游阶段，复用有效 runtime、checkpoint 和已有检查记录。只对新失败或明确疑点补做受影响检查；不另行重算一份完整世界、不自动展开全部主题截图、不因代理的审美偏好反复微调。阻塞修复集中完成后只在最终交付时打包发布一次。skill 文档修改不要求重发计算包。

相关测试共 79 项通过，覆盖 SciPy 区间系数逐位一致、经度周期、极地截断、退化尺寸、标量分批边界、向外舍入证书、真实细等高线与 spawn 后的串行/并行顶点一致。已通过的检查不继续扩大为完整世界复现。

# 连续河口与离岸陆点 · dev23

水文网格的 D8 邻接允许对角流动。两个原生陆地中心可能通过对角线相邻，但它们之间的连续地面仍为海水，尤其是主大陆与很薄的小离岸陆点。旧河岸接近求解要求终端段在原有横向走廊内保持干地，整个合法横截面都湿时就失败。

dev23 在终止于真实岸线的河段中处理这一情况。只有原有合法走廊的横截面找不到干地时，河段才在上游陆地进入水域的连续高程零点结束。仍有可通行干岸的海湾保留绕岸求解；非终端河段不能借此截断。保留上游河流，不跨海连接小离岸陆点，也不修改 D8、水掩码或原生高程数组。

源河段和实际课程同步使用同一个求解出的河口。河床、细地形、生态用水和运输使用该结果；河床仍按原有非增剖面求解。没有特定世界种子、河流编号或坐标的生产分支。

保存的物理网格只包含原生气候与水文事实，其输入指纹不含连续河道实现。仅修复连续河口时，正常 `generate_world` 可从完整绑定的物理 checkpoint 复用已完成阶段，在新输出目录记录新引擎版本。旧运行记录和旧 checkpoint 不重绑定；后续连续地面、人文、交通、等高线和网页重新计算。

# dev24 命名与同轮数据复用

固定文化词根库存会在大量旧名排除与聚落分配后耗尽。名称注册仍先使用已有短名，再按实体所属文化的完整词素枚举复合名；种子只决定候选顺序。有限的子串约束状态图保留能够接上合法结尾的词素路径，无可用词素或结尾时明确报错，不无限重试。不使用编号、方位补丁或旧名包装，原有精确排除、旧名子串、全世界重复和相邻重字条件保留。

正常完整世界流程现在先准备连续地面、岸线、生态来源与主题数据，再运行人文生成；绘制复用同一轮准备对象。对象绑定物理网格摘要、完整原始物理字段及诊断摘要，输入不匹配立即拒绝。单独绘制仍计算自己的准备数据，没有磁盘缓存、跨版本回退或旧数据重绑定。

四项准备各自记录计时并立即写日志。绘制记录准备来源与复用阶段，不将复用伪记为一次耗时为零的重算。地形、河床、海岸、生态数值和物理分辨率没有因复用而降级。

这两项修改减少固定库存失败与本轮重复计算；它们不保证任意输入都能在十几分钟完成。完整生成耗时仍由实际运行记录报告。

# v1.1.0 · v38 地形引擎与自动下载 skill

首次 GitHub 发布；保留已认可 v38 海岸算法和既有人文链路，不更改原世界地图。

## 下载选择

- `generate-world-atlas-skill.zip`：轻量 skill。先问 15 个世界设定问题，确认参数后自动下载、校验、安装和调用计算包。
- `world_atlas_engine-1.1.0-py3-none-any.whl`：Python 计算包。
- `world-atlas-engine-1.1.0-source.zip`：独立源码、skill、测试、说明和技术路线。
- `accepted-v5-inputs.zip`：仅历史人文复现需要，新世界不默认下载。
- `release-manifest.json`：上述四个附件的文件长度与 SHA-256。

## 环境和验证

需要 Python 3.14。完整地图另需 Node.js/npm；本地验收环境为 Windows、Python 3.14.0、Node 22.21.0。首次安装需联网，生成阶段不调用 AI 或网络。安装器不修改系统环境，不覆盖已有目录。

本地 27 项测试通过，覆盖计算接口、海岸回归、十五题入口、共享边界、下载完整性、缓存和拒绝覆盖。v38 全尺寸同环境复现已验证；不能由此推断所有种子都已通过地理/美术验收或跨平台位级一致。

使用说明见仓库 README；技术路线见 `docs/TECHNICAL_ROUTE.md`。仓库公开但尚未指定开源许可证。

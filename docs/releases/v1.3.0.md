# 1.3.0

This release updates the physical terrain generator while preserving the existing rendering style and the accepted v38 world.

- Adds segmented, motion-aware continental margins and a distance-coupled fault-block shelf field for less circular coastlines.
- Adds directional folded orogenic belts with parallel ranges, relay gaps and inherited paleo-sutures.
- Adds reference-grid shelf fragments, island arcs and hotspot groups before sea-level classification.
- Keeps the full-resolution synthesis grid, deterministic seeds and the left/right ocean seam constraint.

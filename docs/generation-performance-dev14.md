# 生成提速：1.4.0.dev14

本版只改变计算调度和地图导出中的重复工作。物理分辨率、轮廓求根精度、100 米细等高线间隔、专题图层、城市规则和画法均保留。已有世界不重新生成。

## 耗时证据

格温卡瑞的原始记录：气候水文 159.667 秒，人文 305.387 秒。一次保存模型的完整绘制调用耗时 5292.45 秒，末尾预览创建失败；在失败前全部主瓦片和城市细地形已写完。

保存文件的时间范围显示三个主瓦片层约耗时 25 分 39 秒，城市细等高线约耗时 34 分钟。文件时间用于定位责任层，不作为受控速度对照。

## 改动

- 三个缩放层级逐瓦片交错导出，同一源几何的精确裁切只算一次。缓存每个瓦片后清空，内存不随全图瓦片数增长。
- 按当前瓦片实际引用生成图形 ID，避免每块瓦片创建全部世界要素的 ID 字符串。
- 局部细地形查询与全图查询共用并行入口，最多使用四个进程。各进程负责一批相邻高度，继续共享高度无关的范围和梯度证书，保留原生空间批次和每个高度的完整连接图。小任务保留串行执行。
- `review/timing.json` 分别记录主瓦片、城市细等高线和城市地形瓦片耗时，包括失败阶段。

并行回归实际启动独立进程，对照串行输出的高度顺序、空高度和每一个曲线顶点的 binary64 位。瓦片回归对照各层单独导出与共享导出的全部 JSON 字节，并覆盖城河交点、岛湖孔洞、道路接缝、曲线和图形 ID。

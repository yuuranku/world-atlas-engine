# 验收与交付

## 四类分别判断

1. 程序正确性：哈希/schema、有限数值、数组对齐、交通合法、板块同源、省份覆盖、名称和引用。
2. 复现：玩家要求复现或确定性回归时，同源/配置/版本/种子在独立目录重算，比较物理、人文和实体语义指纹；普通生成保存指纹，不再重算一份世界。
3. 地理：全图和局部有解释，不将“无报错”当“真实”。
4. 表达：配色、文字、共享边、缩放、移动、层级可读。

不能一类冒充全部通过，不能删失败样本、放宽阈值或换种子隐藏回归。

当前地形基准为玩家已认可的 v38，指纹在 `assets/terrain-v38.acceptance.json`。认可只覆盖这一版地形与海岸表现，不代表任意新种子或重建后的人文自动通过。

## 实际看图

普通生成打开一次全图，复用已保存的截图和检查记录即可交付。以下区域清单用于专项审计或定位已出现的错误，不是每次生成都必须执行的第二套流程。受影响检查通过后停止扩大验收范围。

- 全图：大小距离、连续洋盆、海岛层次和左右海洋。只留主要山系/河流/群岛/大地理，小岛名放大再显。
- 区域：不同海岸、不同山系及山麓、盆地平原高原、汇合及河口、陆架与洋盆。
- 海岸修复：增加纯海陆轮廓及玩家指定岸段的同坐标前后对照；长岸线应有不等长的内凹、外凸与转折，而非一条大圆弧或重复尖角。周长/复杂度增加不等于验收通过。
- 政区：边线/填色重合、交汇无白缝、小国非方块、省界虚线和分色完整。
- 最大缩放：城市填描比例、形态和标签锚点稳定，线不能细到消失或粗到吞底图。
- 交互：拖缩锚点、主题、资源加载、全图复位。现代清晰字体、都城加粗；国界较深长虚线，省界较细短虚线。

沿用现有 SVG/等高线画法；降卡顿先查重绘、事件、DOM/路径量、缓存，不偷偷降计算分辨率。

## 记录与工具

保留配方、17 答/确认参数、种子、代码/依赖版本、输入指纹、引擎内建检查、命名审计和实际截图。数据未变时复用原记录，不重复重算、截图或审计。

只有专项浏览器审计才运行 `node scripts/capture_review.mjs <世界输出> [msedge|chrome|chromium]` 检查全部主题并截图；所需依赖只在缺失时安装，不每次执行 `npm ci`。普通交付使用已有浏览器打开一次首页。没有浏览器就说明，不造截图。

将通过、执行失败、未执行分开。例如 v36 两个旧地形审美回归门槛并不因打包自动通过。

## 发布

页面为 `<输出>/review/index.html`。使用简短 ASCII 输出路径，以 `Path.as_uri()` / `pathToFileURL()` 构建 URL，不重复编码。

检查文件/资源并实际打开后提供链接。file URL 不可用时，可在指定输出目录开启仅绑定 `127.0.0.1` 的静态服务，不自动公网发布。

每版至少一张实际全图加必要局部，简短讲变化、保留项和限制。安装/打包没有新世界时明确当前地图未变，不另造图凑交付。

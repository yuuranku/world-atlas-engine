# 地理判断与参考方法

## 世界尺度

先看大陆大小梯度、纬度分布、连续洋盆和组合，再看细节。避免均匀椭圆陆块、同宽海峡、同长度山脉、一座山支撑一个大陆。不复制地球轮廓，借鉴构造关系和尺度。

用连续形态轴理解种子：构造周期、聚合、破碎、小板块、岛弧、热点、纬度偏向、半球非对称、洋盆开放度。生成后分类，不把玩家举例当作世界全部类别。

左右边缘始终为海，大陆不被显示接缝割开。选合法海洋接缝/中央经线，不削大陆凑条件。

## 唯一地表

板块及运动 → 陆/洋壳与年龄 → 裂解汇聚、基面、海平面 → 山系/盆地/高原/海底 → 气候侵蚀水文 → 展示与人文。

海岸、海深、陆高、等高线和河网来自同一连续地表/零水位。河不能只浮在填色上，跨河成本与桥位必须使用同源河道。

允许合理海岸山脉和构造直岸。错的是缺乏山麓、陆架、侵蚀或构造解释的突然截断、统一圆滑和轴向切割，不是“所有山碰海/直段都错”。

| 对象 | 看什么 | 避免什么 |
| --- | --- | --- |
| 海岸 | 岬湾嵌套、溺谷、沉积岸、岩岸和岛弧条件 | 同频锯齿、椭圆切口、平直裁边 |
| 山系 | 走向、复合脊、变宽、山麓、前陆盆地和高原过渡 | 同心山包、孤立亮条、每条山等高线一样 |
| 内陆 | 古低地、冲积平原、高低盆地、台地丘陵邻接 | 所有沙漠同高、平原无信息、盆地全规则圆 |
| 河湖 | 集水坡向、谷地、汇合、入海入湖或合法内流 | 跨脊直线、梳齿支流、空中河口 |
| 海底 | 陆架—陆坡—洋盆、扩张脊、沟弧关系 | 用色差纹理当海沟、全海同深、随机大直线 |
| 岛屿 | 陆架碎片、岛弧、热点链和尺寸差 | 没岛、每岛一个圆锥、同距排队 |

拓扑正确与地理可信分开。噪声仅补受约束残余，不能替代山系/流域。平滑改善表达，不改真值凑视觉。

## 长岸线的分段起伏（v36/v5 修正依据）

旧 v36/v5 的海岸过于平滑；修正后的 v38 已由玩家在 2026-09-05 认可，作为当前地形基准。历史版的验收缺口仍保留记录，不能把新基准的认可倒推给旧算法。

- 1.0.0 的基底岸形共享正弦弯轴和变宽轮廓。局部有细节，但长岸线仍容易一条顺滑的大弧线滑到底。
- `_spherical_fbm` 与 coastal micro detail 提供细节，但不是独立的断层、岩性、溺谷和沉积岸演化。
- 网页 `_naturalize_surface_path` 用统一 0.72 单元简化、alpha=.22、一遍 Chaikin，会弱化局部转折；原始 PNG 已有圆弧，因此渲染不是唯一主因。
- 玩家 2026-09-05 红线示例明确要求：保持大陆整体走向，沿岸有不等长的内凹、外凸和方向转折。不是把大陆重塑成巨型尖角，不是只添加像素毛刺，也不是所有岸段都折线化。
- 原始海陆掩膜和同坐标岸段必须对照。改变早期地壳势场会连带大幅重排内陆；局部水体切口不足以改变长弧；过强统一位移会产生重复尖角。这三类结果不能仅凭周长增加而接收。
- 1.1.0 在最终海平面截取前对连续地表施加分段陆缘位移，沿岸地形一起移动，随后再算海陆和侵蚀。速度/持续期控制位移预算，平静沉积岸可不改。它是程序化近似，不是校准过的地质历史；当前板块速度不是被动陆缘形成史的完整解释。
- 保留固定种子/源及已认可人文，另建地形候选。对照通过后才重算依赖海陆变化的下游，不把旧政治交通图直接叠在新地形上。

## 参考入口

具体判断时打开原文及地图，记录日期、观察区域、可借鉴机制、与本世界差异。资料是研究入口，不是引擎联网依赖。

- [NOAA ETOPO](https://www.ncei.noaa.gov/products/etopo-global-relief-model)：全球陆地和海底的连续地形与尺度。
- [NPS 海岸地貌](https://www.nps.gov/subjects/geology/coastal-landforms.htm)：侵蚀/沉积、波潮、供沙和地质历史区分海岸。
- [Red Blob 球面地图](https://www.redblobgames.com/x/1843-planet-generation/)：布局与板块形态，也读作者的失败记录。
- [Worldengine](https://github.com/Mindwerks/worldengine)：板块、降水、侵蚀模块及种子组织，不盲换整套画法。
- [Azgaar](https://github.com/Azgaar/Fantasy-Map-Generator)：交互、命名、城市和政区组织；幻想地图观感不是物理证据。
- [Mapshaper](https://github.com/mbloch/mapshaper)：共享边与多边形拓扑，检查锁定版本 API。
- [USGS 构造资料](https://pubs.usgs.gov/gip/dynamic/understanding.html)：汇聚/张裂/转换解释；拒绝访问时换官方入口，不声称已读。

2026-09-05 已核对 ETOPO、NPS、Red Blob、Worldengine、Azgaar；USGS 此入口本次 403，未据其新增具体断言。

## 每轮研究记录

问题截图与范围、原假设、真实类比及来源、实现或论文参考、修改层、预期改变/不变项、同种子对照、实测结论。陌生或反复失败的问题主动找原始论文与官方资料，不连续硬调同一办法。

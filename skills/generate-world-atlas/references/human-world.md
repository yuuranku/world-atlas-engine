# 人文链路与命名

地形先可用。城市、交通、文化、宗教、国家、省份是关联链路，不能只换标签或把旧格局贴到新大陆。

## 城市与交通

- 绘出的河是主要河流，不是全部水源。允许支流、泉水、农业、矿产、贸易节点、驿站和山口造城。
- 用权重表达宜居/资源/通达性，不强制城市吸附主河。
- 国界附近道路、山口、桥头提高要塞/关隘倾向，不给全部边城同一角色。
- 河流/山地阻隔优先于商贸扩张奖励。桥是真实道路与河网交点，不是图标抹除全河阻力。
- 陆路不穿海，海路内部不跨陆，港口端点可落港城。都城、省治、路网共用城市 ID。

## 政区与文化

- 国界参考山系、分水岭、宽河、通道、文化连续和统治成本，不把整流域套成一国。
- 保留大中小国；小国须有港湾、山谷、关口或城市腹地，而非方块/面条。
- 部落/游牧是实际社会空间，不是失败的无人区；默认参考球面陆地约 35%。玩家改变意图时先检查配置接入。
- 修零碎无理由空洞，不挤掉合理部落腹地。
- 省界/国界共用物理约束与拓扑，省份必须分色并有真实划分虚线，不能只有名字。
- 文化可跨国，宗教可跨文化；圣城为城市属性，引用一致。

## 专名与表达

- 按文化生成完全架空音系词根，保持内部风格，不用旧词库。
- 将已用世界专名加入 `--exclude`；核对世界、板块、大陆、海洋、山川、国家、省份、文明、语言、宗教、部族与城市。
- 保留河、山脉、王国、共和国等通称；共和国不加“海洋共和国”。
- 行政称呼匹配文化：西方可用伯国、边区、总督领、领地等，不统一“军州”；海/港称呼满足地理条件。
- 稳定 ID，统一更新都城、省治、发源地、圣城；只替换 SVG 文字不算重命名完成。
- 都城加粗、圣城有可辨样式；缩放保留符号形状、填描比例和文字锚点。

修负责字段的计算层，重算受影响下游，不移动地形迁就城市，不靠改名掩盖坏领土。
